## 확인 필요

- 5페이지 문의 전화번호 뒤의 `??? (전용)`은 PDF에도 물음표 세 개로 표시되어 있습니다. 원문을 임의 추정하지 않았습니다.
- 4페이지의 인용부호는 `보유한“(주)소프트파워’`처럼 여는 부호와 닫는 부호가 서로 다르게 보입니다. 원문 그대로 기록했습니다.
- 4페이지 소개문의 종결 기호는 `과정입니다,`로 쉼표입니다. 원문 그대로 기록했습니다.
- 6페이지 표의 `Gamma 4`는 사용자 지정 예외 규칙(`Gemma`는 `Gamma`로 정정)을 반영한 표기입니다.
